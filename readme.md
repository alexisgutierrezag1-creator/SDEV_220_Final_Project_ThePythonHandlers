Project Description

***Who is the client?***

The client is a fictitious company named Care Incorporated or Care Inc. for short.

***What is the scope of the system?***

The system will handle creating and deleting accounts. There will be user accounts (parents) and professional accounts (babysitters). 
Updating account information. 
Direct account lookup. Both babysitters and parents would be able to look each other up. 
Babysitter profile suggestions based on Parent user location. 
Babysitters will be able to apply for work based on parent listings. 
Parents will be able to request work from babysitters based on the babysitters' availability.

***What is the purpose of the system?***

The purpose of the system is for parents to be able to look up a babysitter with the appropriate qualifications for their needs in their area, and for babysitters with various levels of experience and qualifications to find work.
